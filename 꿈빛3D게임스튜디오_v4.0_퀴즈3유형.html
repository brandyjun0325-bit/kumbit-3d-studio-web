    🎮 게임 규칙 · 🛠 맵 만들기
      🔑 Google Gemini API 키 (무료)
      ① aistudio.google.com/apikey 에 구글 계정으로 로그인 → Create API key (카드 등록 없음)
      ② 만들어진 키(AIza…)를 아래에 붙여넣고 연결 테스트를 누르세요.
      🧠 모델
      무료 사용 가능한 Flash 계열을 권장해요. 모델을 쓸 수 없으면 다른 무료 모델로 자동 전환해요.
      🔒 개인정보 · 안전
      · 키는 이 브라우저에만 저장되고, 📦 게임 내보내기 파일에는 절대 들어가지 않아요.
      · 무료 등급에서는 입력한 내용이 구글 서비스 개선에 쓰일 수 있어요. 학생 이름·연락처 등 개인정보를 입력하지 마세요.
      · 요청 때 보내는 정보: 내가 쓴 요청, 월드의 파트 목록(이름·종류·위치), 스크립트 코드.
      · AI가 만든 코드는 이 스튜디오의 안전 규칙(전역 접근 차단·무한 반복 정지) 안에서만 실행돼요. 적용 후 마음에 안 들면 ↶ 실행 취소.
      · API 키가 없어도 📋 프롬프트 복사 → 다른 AI에 붙여넣기 → 📥 답변 붙여넣기로 똑같이 쓸 수 있어요.
